THE DESIGN CHALLENGE

Banking, made clear.

Banking workflows need clarity at every step. This concept explores how a simple interface can support careful review before a transaction is confirmed.

Proposed capabilities

01

Account overview

A readable view of account balances, recent activity, and summary information.

02

Guided transfers

A multi-step transfer flow with validation, recipient review, and confirmation.

03

Traceable activity

Transaction references, clear statuses, and a proposed audit trail.

A possible system shape

React interface → authenticated Spring Boot API → PostgreSQL

What would come next

Validate user needs, agree on acceptance criteria, build a small working slice, and verify behavior with functional tests. Security, accessibility, error handling, and observability would be part of implementation review.

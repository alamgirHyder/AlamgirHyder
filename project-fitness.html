THE DESIGN CHALLENGE

Small steps. Better days.

Fitness information is easier to act on when daily progress is readable at a glance. Motion explores a calmer presentation of activity and recommendations.

Proposed capabilities

01

Activity recognition

A proposed activity view informed by the KNN approach used in my university project.

02

Daily progress

Illustrative steps, distance, and activity summaries with clear visual hierarchy.

03

Personal guidance

BMI tracking and workout recommendations, reflecting features described in my CV.

A possible system shape

Android sensor input → activity features → KNN classification → progress view

What would come next

Validate user needs, agree on acceptance criteria, build a small working slice, and verify behavior with functional tests. Security, accessibility, error handling, and observability would be part of implementation review.
